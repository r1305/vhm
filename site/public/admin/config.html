🔗 Verificación de Dominio (Meta)

Código de verificación de dominio proporcionado por Meta (Facebook/Instagram). Se inyecta como <meta name="facebook-domain-verification"> en el landing.

ℹ️ ¿Cómo obtener este código?

1. Ve al Panel de Desarrolladores de Meta.

2. Selecciona tu aplicación.

3. Ve a Configuración → Básico.

4. En "Verificación de dominio", agrega tu dominio y copia el código meta.

5. Pega solo el valor del content en el campo de arriba.

ℹ️ ¿Cómo obtener las credenciales?

1. Ingresa a mercadopago.com.pe/developers/panel.

2. Crea o selecciona una aplicación.

3. En Credenciales encontrarás la Public Key y el Access Token tanto para Sandbox como para Producción.

4. Usa las credenciales de Sandbox para pruebas y las de Producción cuando vayas en vivo.

5. Configura el webhook en Mercado Pago apuntando a (evento Orders).

6. En el servidor, define SITE_URL con la URL pública del sitio (ej. https://tudominio.com/site) y opcionalmente MP_WEBHOOK_SECRET para validar la firma.
