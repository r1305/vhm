🔗 Verificación de Dominio (Meta)

Código de verificación de dominio proporcionado por Meta (Facebook/Instagram). Se inyecta como <meta name="facebook-domain-verification"> en el landing.

ℹ️ ¿Cómo obtener este código?

1. Ve al Panel de Desarrolladores de Meta.

2. Selecciona tu aplicación.

3. Ve a Configuración → Básico.

4. En "Verificación de dominio", agrega tu dominio y copia el código meta.

5. Pega solo el valor del content en el campo de arriba.

ℹ️ ¿Cómo obtener las credenciales?

1. Ingresa a CulqiPanel (Integración o Producción).

2. Ve a Desarrollo → API Keys y copia Public Key y Secret Key.

3. La Tribu usa Culqi Checkout (token) + API de Cargos y Tarjetas para guardar medios de pago y autorenovación.

4. Configura el webhook en Culqi apuntando a (evento charge.succeeded).

5. En el servidor define SITE_URL, TRIBU_RENOVACION_CRON_SECRET y opcionalmente CULQI_WEBHOOK_SECRET.

6. Programa un cron HTTP diario a /api/tribu-pagos/cron-renovaciones?token=... para renovaciones con tarjeta guardada.

7. Tarjeta de prueba: 4111 1111 1111 1111, CVV 123, vencimiento futuro.
