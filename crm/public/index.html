Instagram / Meta Lead Ads Configurar

Webhook URL:

1. Ve a Meta for Developers → tu app → Webhooks
2. Suscribe al objeto page, campo leadgen
3. Pega la URL y el Verify Token de arriba

TikTok Lead Generation Configurar

Webhook URL:

1. Ve a TikTok for Business → tu app → Events
2. Sección Lead Generation Webhook
3. Pega la URL y el App Secret de arriba

WhatsApp (openwa) Sin configurar

1. Abre vhm.com.pe/openwa, inicia sesión y copia el Session ID
2. En API Keys copia o crea una API Key con rol operator
3. Pega los datos aquí y presiona Probar
